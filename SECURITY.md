# Security policy

## Reporting a vulnerability

Please report security problems privately, by email to **souschef.feedback@gmail.com**, and not in
a public issue or pull request.

It helps to include what you found, the steps to reproduce it, and what an attacker could do with
it. You will get a reply as soon as the maintainer can manage; this is a one-person project, so
please allow a few days.

Please give a reasonable amount of time for a fix before disclosing the problem publicly, and do not
test against other people's accounts or data on the live service.

## Scope

The code in this repository and the service it runs at https://trysouschef.vercel.app.

## Supported versions

Only the latest release is supported.
